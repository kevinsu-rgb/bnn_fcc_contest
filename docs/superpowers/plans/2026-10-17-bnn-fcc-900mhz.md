# BNN_FCC 900 MHz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Every `N.V` and `N.D` task is executed by a different subagent** (see Separation Rules).

**Goal:** Implement `bnn_fcc` (AXI4-Stream BNN classifier, SFC 784→256→256→10) at one image per 98 cycles, closing 900 MHz on `xcu250-figd2104-2L-e` with LUTRAM memories, verified by UVM 1.2 unit/integration environments on xsim.

**Architecture:** Layer-pipelined dataflow (spec Approach A). Each computing layer is one `bnn_layer` (sequencer → registered broadcast tree → PN neuron processors with private weight/threshold RAMs), separated by double-buffered `bnn_act_buf`s using a claim/commit/release slot handshake, so no stall net exists. A byte-serial `bnn_cfg_mgr` parses config messages in any order and writes memories over a broadcast write bus while the pipeline is drained.

**Tech Stack:** SystemVerilog IEEE 1800-2012 (synthesizable RTL), Vivado 2025.2 (synthesis/implementation, xsim + UVM 1.2), Verilator 5.020 (lint), openflex 0.1.4.

**Spec:** `docs/superpowers/specs/2026-10-17-bnn-fcc-900mhz-design.md` — read it first; section numbers (§) below refer to it.

**Refinements vs spec (no behavior change):**
- `rtl/bnn_fcc_derive.svh` holds per-layer derivation functions shared (via `` `include ``) by every module that has the `TOTAL_LAYERS/TOPOLOGY/PARALLEL_INPUTS/PARALLEL_NEURONS` parameters. It is never listed as a compile unit.
- `rtl/bnn_bcast.sv` is the reusable replicated-register broadcast tree (§7.2, §5.4 reset tree).
- `rtl/bnn_core.sv` = Buf0 + layers + inter-layer buffers + argmax (the DUT of the spec's `bnn_core` env).
- `bnn_np` carries no valid bit: tokens inside an image are contiguous, `first` resets the accumulator, and the layer keeps a single reset-able shadow pipeline (valid/last/group) aligned to NP latency.
- `bnn_act_buf` slot states are EMPTY → CLAIMED → FULL → EMPTY with separate claim/write/read pointers; this lets a producer hold two images in flight (needed for zero-bubble starts) and lets the gearbox claim eagerly without blocking drain.

## Separation Rules

Each module is delivered by two tasks executed by **different subagents**, in this order: **N.V** (verification) then **N.D** (design). Both work from the same contract: the task's **Interfaces** block plus the spec.

| | Verification agent (`N.V`) | Design agent (`N.D`) |
|---|---|---|
| May edit | `verification/unit/**`, `sim/**` (except `sim/lint.sh`) | `rtl/**`, `synth/**`, `sim/lint.sh`, and the allowed lines in `verification/bnn_fcc_tb.sv` / `openflex/**` (Global Constraints) |
| May read | spec, plan, provided `verification/*.sv`, `python/**` | spec, plan, test sources and logs (read-only), everything in `rtl/`, `synth/` |
| Must not | read anything under `rtl/` or `synth/`; import `bnn_fcc_pkg` (except the `pkg` env, which tests it) — expected values come from `bnn_ref_pkg`, an independent implementation of the plan's formulas | edit any file under `verification/unit/**` or `sim/**` other than `sim/lint.sh` |
| Done when | env compiles and runs against its **port-accurate stub** DUT (`verification/unit/<env>/stub/`) and every test reports `RESULT: FAIL reason=scoreboard` or `reason=timeout`, never `compile`/`elab` | every listed test × pset reports `RESULT: PASS`, probes `RESULT=PASS`, lint clean |

**Disputes:** if a design agent believes a test contradicts the spec or plan, it stops with status `BLOCKED: test dispute`, citing the test, the log line, and the spec/plan clause. The controller (reviewer or user) rules; any test change is made by a verification agent in a follow-up `N.V-fix` task.

**Stubs:** a stub has exactly the Interfaces-block module header, ties every output to `'0`, and contains no behavior. `STUB=1 sim/run_unit.sh ...` compiles `stub/*` instead of the env's `dut.f`.

## Review Focus

1. **`TOTAL_LAYERS = 2`** (input → output layer only, no hidden layer, no thresholds at all): must classify correctly and assert `data_in_ready` after weights alone. Pinned by pset `t2` in 8.V (`core_random_test`) and 12.V (`top_smoke_test`).
2. **Reset mid-message / mid-image / with outputs pending:** after reset the next config must parse from header byte 0 and no stale partial image or result may surface. Pinned by `cfg_reset_midmsg_test` (11.V) and `top_reset_phases_test` (13.V).
3. **Live reconfiguration while `data_out_ready` is held low** (output FIFO full): no deadlock; images started before the reconfig use the old model, later ones the new. Pinned by `top_live_reconfig_backpressure_test` (13.V).
4. **Packed config stream** (messages not padded to beat boundaries, a message starting mid-beat, header straddling beats) on 8-, 32- and 512-bit config buses. Pinned by `cfg_packed_stream_test` with psets `bus8`, `bus32`, `bus512` (11.V).
5. **Zero-gap back-to-back images:** each layer must start a new image exactly C·G cycles after the previous; the top must sustain ≤ 98 cycles/output with continuous input. Pinned by `layer_back_to_back_test` (6.V) and `top_throughput_test` (13.V).

## Shared conventions

**Unit environment layout** — `verification/unit/<env>/`:
- `<env>_tb.sv`: top module `<env>_tb`; DUT parameters from `` `PSET_* `` macros; sets virtual interfaces in `uvm_config_db`; calls `run_test()`.
- `<env>_pkg.sv`: UVM classes (items, sequences, drivers, monitors, scoreboard, coverage, env, tests).
- `<env>_if.sv`: interfaces for the DUT ports (AXIS ports reuse `verification/axi4_stream_if.sv`).
- `psets/<name>.svh`: only `` `define PSET_<NAME> <value> `` lines.
- `dut.f`: the DUT's own RTL files; `deps.f`: previously delivered RTL it needs (always starting with `rtl/bnn_fcc_pkg.sv`); `tb.f`: common + env files (paths relative to repo root, compile order).
- `stub/`: port-accurate stub(s) of the DUT file(s).

**Scoreboards** extend `bnn_scb_base` (1.V): `report_phase` prints `SCB: <name> checked=<n> mismatches=<m>` and raises `uvm_error` if `checked == 0` or `mismatches != 0`. Every test has a watchdog (`uvm_fatal` after a per-test cycle budget) so a stub cannot hang.

**Run a test:** `[STUB=1] sim/run_unit.sh <env> <pset> <test> [seed]` → last line `RESULT: PASS env=<env> pset=<pset> test=<test> seed=<seed>` (exit 0) or `RESULT: FAIL reason=<compile|elab|scoreboard|timeout> ...` (exit 1). Regression: `sim/regress.sh` runs every line of `sim/regress.list` (`<env> <pset> <test>`), prints `REGRESS: <p> passed, <f> failed`, and merges coverage into `sim/cov_report/`.

**Probe a module:** `vivado -mode batch -nolog -nojournal -source synth/probe.tcl -tclargs <top> <tag> [GEN=VAL ...]` → prints `PROBE <top> <tag> WNS=<x> WHS=<y> WPWS=<z> RESULT=PASS|FAIL`.

**Standard V steps** (each V task lists its tests and psets, then follows these):
1. Write stub, interfaces, tb top, pkg classes, psets, `dut.f`/`deps.f`/`tb.f`.
2. `STUB=1 sim/run_unit.sh <env> <pset> <test>` for every test × pset → each `RESULT: FAIL reason=scoreboard` or `reason=timeout`.
3. Append the test × pset lines to `sim/regress.list`.
4. Commit `verification/unit/<env>` (+ common-pkg changes) and `sim/regress.list` with message `Add <env> UVM environment` + trailer.

**Standard D steps** (each D task lists its files, probes and lint tops, then follows these):
1. `sim/run_unit.sh <env> <first pset> <first test>` → `RESULT: FAIL` (DUT missing).
2. Implement the RTL per the Interfaces block; append new files to `synth/files.f`.
3. Run every test × pset of the module's V task → all `RESULT: PASS`. On a failure: read the log, fix RTL; if the test contradicts spec/plan → `BLOCKED: test dispute`.
4. Run the listed probes → each `RESULT=PASS`.
5. `sim/lint.sh <top>` for each new module → no output, exit 0.
6. Commit `rtl/…`, `synth/…` with the listed message + trailer.

### Task 2: `bnn_ram` — memory wrapper

**Interfaces:**
```
module bnn_ram #(int WIDTH=16, int DEPTH=98, string RAM_STYLE="distributed",
                 int READ_LATENCY=1, string PORTS="SP") (
  input  logic clk,
  input  logic we, input logic [addr_w(DEPTH)-1:0] wr_addr, input logic [WIDTH-1:0] wr_data,
  input  logic [addr_w(DEPTH)-1:0] rd_addr, output logic [WIDTH-1:0] rd_data);
```
`PORTS="SP"`: `rd_addr` addresses both write and read; `wr_addr` ignored. `PORTS="SDP"`: independent ports, read-before-write on the same address. `rd_data` = contents at `rd_addr` sampled `READ_LATENCY` cycles earlier. No reset. Elaboration error for unknown `RAM_STYLE`/`PORTS` or `READ_LATENCY < 1`.

### Task 5: `bnn_act_buf` — double-buffered activation buffer

**Interfaces:**
```
module bnn_act_buf #(int WIDTH=16, int DEPTH=49, string RAM_STYLE="distributed", int READ_LATENCY=1) (
  input  logic clk, rst,
  output logic wr_can_claim, input logic wr_claim,
  input  logic wr_en, input logic [addr_w(DEPTH)-1:0] wr_addr, input logic [WIDTH-1:0] wr_data,
  input  logic wr_commit,
  output logic rd_full, input logic rd_en, input logic [addr_w(DEPTH)-1:0] rd_addr,
  output logic [WIDTH-1:0] rd_data, input logic rd_release,
  output logic idle);
```
Two slots EMPTY/CLAIMED/FULL with round-robin claim, write and read pointers. `wr_can_claim` = slot at claim pointer EMPTY; `wr_claim` → CLAIMED. Writes and `wr_commit` apply to the oldest CLAIMED slot; commit → FULL. `rd_full` = slot at read pointer FULL; reads address it; `rd_release` (on or after its last `rd_en`) → EMPTY. Status outputs registered (a claim/commit/release is visible the next cycle). `rd_data` latency = `READ_LATENCY`. `idle` = no slot FULL.

**Files:** `verification/unit/act_buf/**`.

Psets: `regs` (128, 2), `ram49` (16, 49), `ram32` (8, 32), `d1` (3, 1), `bram` (16, 49, block, 2).

**Interfaces:**
```
module bnn_layer #(int LAYER_ID=0, int N=784, int M=256, int PW=16, int PN=128, bit IS_OUTPUT=0,
                   string RAM_STYLE="distributed", int READ_LATENCY=1,
                   int WB_NP_W=7, int WB_ADDR_W=7, int WB_DATA_W=128) (
  input  logic clk, rst,
  input  logic cfg_mode, cfg_wr_valid, input logic [7:0] cfg_wr_layer, input logic cfg_wr_kind,
  input  logic [WB_NP_W-1:0] cfg_wr_np, input logic [WB_ADDR_W-1:0] cfg_wr_addr,
  input  logic [WB_DATA_W-1:0] cfg_wr_data,
  input  logic in_full, output logic in_rd_en, output logic [addr_w(C)-1:0] in_rd_addr,
  input  logic [PW-1:0] in_rd_data, output logic in_release,
  input  logic out_can_claim, output logic out_claim,
  output logic out_wr_en, output logic [addr_w(G)-1:0] out_wr_addr,
  output logic [PN-1:0] out_wr_data, output logic out_commit,
  output logic res_valid, res_last, output logic [PN*width_for(N)-1:0] res_counts,
  output logic [PN-1:0] res_mask,
  output logic idle);
```
(C = `ceil_div(N,PW)`, G = `ceil_div(M,PN)`.) Behavioral contract:
- Write bus applies only when `cfg_mode && cfg_wr_valid && cfg_wr_layer == LAYER_ID`. `cfg_wr_kind = 0`: weight word `cfg_wr_data[PW-1:0]` for NP `cfg_wr_np` at address `g·C + c`; `= 1`: threshold `cfg_wr_data[TW-1:0]` (TW = `width_for(N+1)`) at address `g` (hidden only).
- Image start requires `in_full && out_can_claim && !cfg_mode`; it pulses `out_claim` once. The layer reads every chunk of the input slot once per group, pulses `in_release` once per image, and can start the next image the cycle after its last read (zero bubble: consecutive `out_claim`s exactly C·G cycles apart when inputs/outputs are always available).
- Hidden (`IS_OUTPUT=0`): for each group g writes one PN-bit word to `out_wr_addr = g` — bit p = `(popcount(neuron g·PN+p) >= threshold)`, 0 when `g·PN + p >= M` — then pulses `out_commit` after group G−1. `res_*` tied 0.
- Output (`IS_OUTPUT=1`): one `res_valid` per group, in group order, with `res_counts[p*AW +: AW]` = popcount of neuron `g·PN + p`, `res_mask[p] = (g·PN + p < M)`, `res_last` on group G−1. `out_claim` reserves a FIFO credit; `out_wr_*`/`out_commit` tied 0.
- `idle` = no image being read and no result pending.
