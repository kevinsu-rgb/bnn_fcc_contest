# BNN_FCC 900 MHz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `bnn_fcc` (AXI4-Stream BNN classifier, SFC 784→256→256→10) at one image per 98 cycles, closing 900 MHz on `xcu250-figd2104-2L-e` with LUTRAM memories, verified by UVM 1.2 unit/integration environments on xsim.

**Architecture:** Layer-pipelined dataflow (spec Approach A). Each computing layer is one `bnn_layer` (sequencer → registered broadcast tree → PN neuron processors with private weight/threshold RAMs), separated by double-buffered `bnn_act_buf`s using a claim/commit/release slot handshake, so no stall net exists. A byte-serial `bnn_cfg_mgr` parses config messages in any order and writes memories over a broadcast write bus while the pipeline is drained.

**Tech Stack:** SystemVerilog IEEE 1800-2012 (synthesizable RTL), Vivado 2025.2 (synthesis/implementation, xsim + UVM 1.2), Verilator 5.020 (lint), openflex 0.1.4.

**Spec:** `docs/superpowers/specs/2026-10-17-bnn-fcc-900mhz-design.md` — read it first; section numbers (§) below refer to it.

**Refinements vs spec (no behavior change):**
- `rtl/bnn_fcc_derive.svh` holds per-layer derivation functions shared (via `` `include ``) by every module that has the `TOTAL_LAYERS/TOPOLOGY/PARALLEL_INPUTS/PARALLEL_NEURONS` parameters. It is never listed as a compile unit.
- `rtl/bnn_bcast.sv` is the reusable replicated-register broadcast tree (§7.2, §5.4 reset tree).
- `rtl/bnn_core.sv` = Buf0 + layers + inter-layer buffers + argmax (the DUT of the spec's `bnn_core` env).
- `bnn_np` carries no valid bit: tokens inside an image are contiguous, `first` resets the accumulator, and the layer keeps a single reset-able shadow pipeline (valid/last/group) aligned to NP latency.
- `bnn_act_buf` slot states are EMPTY → CLAIMED → FULL → EMPTY with separate claim/write/read pointers; this lets a producer hold two images in flight (needed for zero-bubble starts) and lets the gearbox claim eagerly without blocking drain.

## Shared conventions (used by every task)

**Unit environment layout** — `verification/unit/<env>/`:
- `<env>_tb.sv`: top module `<env>_tb`; DUT parameters come from `` `PSET_* `` macros; sets virtual interfaces in `uvm_config_db` and calls `run_test()`.

- `<env>_if.sv`: interface(s) for the DUT ports (AXIS ports reuse `verification/axi4_stream_if.sv`).
- `psets/<name>.svh`: only `` `define PSET_<NAME> <value> `` lines.
- `files.f`: source paths relative to repo root, in compile order (RTL deps, common pkg, env files).

Regression: `sim/regress.sh` runs every line of `sim/regress.list` (`<env> <pset> <test>`), ends with `REGRESS: <p> passed, <f> failed`.

**Interfaces:**
- Produces:
  ```
  module bnn_ram #(int WIDTH=16, int DEPTH=98, string RAM_STYLE="distributed",
                   int READ_LATENCY=1, string PORTS="SP") (
    input  logic clk,
    input  logic we, input logic [addr_w(DEPTH)-1:0] wr_addr, input logic [WIDTH-1:0] wr_data,
    input  logic [addr_w(DEPTH)-1:0] rd_addr, output logic [WIDTH-1:0] rd_data);
  ```
  `PORTS="SP"`: one address — `rd_addr` addresses both write and read, `wr_addr` is ignored (tie to `'0`). `PORTS="SDP"`: independent ports. `rd_data` = contents at `rd_addr` sampled `READ_LATENCY` cycles earlier (read-before-write on the same address in SDP). No reset. Inference with `(* ram_style = RAM_STYLE *)`; for `"distributed"` the array read is asynchronous and followed by `READ_LATENCY` output registers; for `"block"`/`"ultra"` the first register is the RAM's synchronous read. Elaboration error for unknown `RAM_STYLE`, `READ_LATENCY < 1`, unknown `PORTS`.

### Task 3: `bnn_popcount` and `bnn_bcast` — pipeline primitives

**Files:**
- Create: `rtl/bnn_popcount.sv`, `rtl/bnn_bcast.sv`; append to `synth/files.f`
- Test: `verification/unit/popcount/`, `verification/unit/bcast/`

**Interfaces:**
- Produces:
  ```
  module bnn_popcount #(int WIDTH=16) (input logic clk,
    input logic [WIDTH-1:0] a, b, output logic [width_for(WIDTH)-1:0] count);
  // count = $countones(~(a ^ b)) of inputs presented popcount_latency(WIDTH) cycles earlier. No reset.
  module bnn_bcast #(int WIDTH=8, int N_OUT=128) (input logic clk,
    input logic [WIDTH-1:0] din, output logic [WIDTH-1:0] dout [N_OUT]);
  // every dout[i] = din delayed exactly bcast_depth(N_OUT) cycles; no reset.
  ```
- Popcount algorithm: leaf stage = groups of 3 bit-pairs → 2-bit XNOR-popcount (one LUT6 per output bit, last group zero-extended), registered; then a balanced binary tree of registered additions, one level per cycle, each sum `width_for(bits covered)` wide. Total latency must equal `popcount_latency(WIDTH)`.
- Bcast algorithm: stage k holds `ceil(N_OUT / 16**(d-1-k))` replicated registers, each driving ≤16 registers of stage k+1; all registers carry `(* keep = "true", shreg_extract = "no" *)`.

### Task 5: `bnn_act_buf` — double-buffered activation buffer

**Files:**
- Create: `rtl/bnn_act_buf.sv`; append to `synth/files.f`
- Test: `verification/unit/act_buf/`

**Interfaces:**
- Consumes: `bnn_ram` (Task 2).
- Produces:
  ```
  module bnn_act_buf #(int WIDTH=16, int DEPTH=49, string RAM_STYLE="distributed", int READ_LATENCY=1) (
    input  logic clk, rst,
    output logic wr_can_claim, input logic wr_claim,
    input  logic wr_en, input logic [addr_w(DEPTH)-1:0] wr_addr, input logic [WIDTH-1:0] wr_data,
    input  logic wr_commit,
    output logic rd_full, input logic rd_en, input logic [addr_w(DEPTH)-1:0] rd_addr,
    output logic [WIDTH-1:0] rd_data, input logic rd_release,
    output logic idle);
  ```
  Two slots, states EMPTY/CLAIMED/FULL, three round-robin pointers. `wr_can_claim` = slot at claim pointer is EMPTY; `wr_claim` makes it CLAIMED. Writes and `wr_commit` apply to the slot at the write pointer (oldest CLAIMED); commit → FULL. `rd_full` = slot at read pointer is FULL; reads address it; `rd_release` (on or after the last `rd_en` of that image) → EMPTY. All status outputs registered; a release/commit/claim is reflected the next cycle. `rd_data` latency = `READ_LATENCY` in both implementations. `idle` = no slot FULL. Storage: registers when `2*DEPTH <= 4`, else `bnn_ram` SDP of depth `2*DEPTH` (slot bit = MSB of the address).

- [ ] **Step 1: Write the failing test** — `actbuf_random_test`: producer agent claims/writes random words to all DEPTH addresses (random order, random gaps)/commits; consumer agent waits `rd_full`, reads all addresses with random gaps, releases; random delays on both sides including claiming the second slot while the first is still being written. Scoreboard: every image read back equals what was written; protocol monitor flags claim without `wr_can_claim`, reads without `rd_full`. Directed `actbuf_zero_bubble_test`: consumer releases on its last read and issues the next image's first read the following cycle; checks data from the new slot. Psets: `regs` (128, 2), `ram49` (16, 49), `ram32` (8, 32), `d1` (3, 1), `bram` (16, 49, block, 2).
- [ ] **Step 2: Verify failure** — FAIL.

  ```
    input  logic [WB_DATA_W-1:0] cfg_wr_data,

    input  logic out_can_claim, output logic out_claim,

    output logic [PN-1:0] out_wr_data, output logic out_commit,
    output logic res_valid, res_last, output logic [PN*width_for(N)-1:0] res_counts,
    output logic [PN-1:0] res_mask,
    output logic idle);
  ```
  (C = `ceil_div(N,PW)`, G = `ceil_div(M,PN)`.) `cfg_wr_kind`: 0 = weight word (`cfg_wr_data[PW-1:0]`, address `g·C + c`), 1 = threshold (`cfg_wr_data[TW-1:0]`, address `g`). Writes apply only when `cfg_mode && cfg_wr_valid && cfg_wr_layer == LAYER_ID`; outside `cfg_mode` the bus is ignored. Hidden layers use `out_*`; output layers use `res_*` (`res_counts[p*AW +: AW]`, `res_mask[p] = (g·PN + p < M)`, `res_last` on the last group) and drive `out_claim` to reserve a FIFO credit. Unused outputs tie to 0.
- Behavior to implement (decided here):
  - **Start rule:** when not issuing (or on the last token of the current image), if `in_full && out_can_claim && !cfg_mode` → pulse `out_claim`, issue tokens `(c, g)` for C·G consecutive cycles with no bubble; `in_release` pulses with the last token. The next image may start the cycle after the last token.
  - **Token root register:** in normal mode carries `{c, g, first, last}` and drives `in_rd_addr = c`; in `cfg_mode` carries `{np one-hot source, addr, data, kind, we}` from the bus (registered once at the root).
  - **Fan-out:** one `bnn_bcast` per signal group from root to the PN NPs/RAMs (`N_OUT = PN`); in cfg mode leaves decode `np == p` to drive that NP's RAM `we`. The input-chunk data path is the buffer read (latency `READ_LATENCY`) followed by its own `bnn_bcast`; the weight path is address `bnn_bcast` followed by the RAM — both total `bcast_depth(PN) + READ_LATENCY`.
  - **Memories per NP:** weights `bnn_ram #(PW, C*G, RAM_STYLE, READ_LATENCY, "SP")`; thresholds (hidden only) registers when `G <= 2`, else `bnn_ram #(TW, G, ..., "SP")`, read with address `g`, delayed so `in_thr` meets `in_last`.
  - **Shadow pipeline:** reset-able `{valid, last_chunk, g}` delayed by `bcast_depth(PN) + READ_LATENCY + np_latency(PW)` selects the cycles where NP outputs are results; hidden: write the PN `out_bit`s, forcing bit p to 0 when `g·PN + p >= M`, to `out_wr_addr = g`, pulse `out_commit` after the last group's write; output: drive `res_*`.
  - **`idle`** = not issuing and shadow pipeline empty.
